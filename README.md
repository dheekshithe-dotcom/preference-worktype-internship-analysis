# Internship Preference vs Work Type Analysis

This project is an interactive Tableau dashboard created to analyze internship job preferences using real-world job data. The dashboard helps users understand how candidates prefer Hybrid, Remote, and Onsite work types across internship opportunities.


## Features

* Preference vs Work Type analysis for internship roles
* Salary filtering and comparison
* Company size based filtering
* Work type distribution (Hybrid, Remote, Onsite)
* Internship job preference insights
* Interactive filters and visual dashboard


## Tools Used

* Tableau Public
* CSV Dataset
* Data Visualization Techniques


## Dashboard Insights

The dashboard provides visual insights into:

* Internship preference distribution across work types
* Comparison of Hybrid, Remote, and Onsite preferences
* Work type trends in internship roles
* Candidate preference patterns based on filters
* Internship hiring behavior analysis


## Dataset Source

“The dataset used in this project is a self-created CSV dataset for internship preference analysis.”

## Project Purpose

The main goal of this project is to simplify internship preference analysis through interactive visualizations and help users understand how work type influences candidate preferences in internship roles.
